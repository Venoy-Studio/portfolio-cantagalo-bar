# Cantagalo Bar · Clone 1:1

Clone fiel e completo do site [Cantagalo Bar](https://cantagalo-bar.vercel.app/), contendo todas as páginas, imagens, fontes, estilos e funcionalidades sem nenhuma alteração.

## 📁 Estrutura de Arquivos

- `index.html`: Página inicial com todo o layout, carrosséis, destaques e mapa interativo.
- `cardapio/index.html`: Página completa de cardápio com busca, filtros por categoria, lista de pratos, porções, bebidas e preços.
- `privacidade/index.html`: Página da política de privacidade.
- `images/`: Todas as 16 imagens originais em formato WebP de alta qualidade.
- `assets/`: Todos os scripts JS, estilos CSS compilados e fontes woff/woff2 (Bitter, Montserrat, Caveat Brush).
- `favicon.png` & `apple-touch-icon.png`: Ícones originais do site.
- `vercel.json`: Configuração pronta para deploy na Vercel com URLs limpas.
- `package.json`: Scripts para execução local.

## 🚀 Como Executar Localmente

### Opção 1: Usando Node / npm
```bash
npm install
npm start
```
Acesse: [http://localhost:3000](http://localhost:3000)

### Opção 2: Usando Python
```bash
python -m http.server 3000
```
Acesse: [http://localhost:3000](http://localhost:3000)

### Opção 3: Usando qualquer servidor estático ou extensão Live Server no VS Code.

## 🌐 Deploy
O projeto está pronto para publicação direta na Vercel, Netlify, Cloudflare Pages ou GitHub Pages sem necessidade de etapa de build.
